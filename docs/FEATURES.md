# 功能说明

这份说明帮助你快速判断：哪些功能可以直接使用，哪些功能需要先准备模型 API 或本地工具。

## 一条完整的创作流程

### 1. 准备故事

你可以直接粘贴剧本，也可以导入小说章节，让对话模型帮助你整理剧情、改编结构和生成分集内容。纯文本录入不需要 API，AI 改编和分析需要先配置对话模型。

### 2. 整理角色与场景

虾客漫会把内容拆成角色、场景、道具和镜头。AI 给出的结果可以继续手动修改，不需要完全照单全收。

### 3. 制作图片资产

你可以上传自己的参考图，也可以调用图片模型生成人物、场景、道具和故事板。上传本地图片不需要图片 API，AI 出图需要自己的图片服务。

### 4. 生成分镜和视频提示词

系统可以生成普通视频提示词，也可以使用故事板模式先安排镜头、机位和画面，再整理成视频模型可用的最终提示词。这一步通常需要对话模型，完整故事板还需要图片模型。

### 5. 生成视频

当前设置界面支持以下方向：

- 本地 Seedance 兼容服务
- Seedance 兼容云端服务
- 小云雀 Agent
- 火山方舟 Seedance
- 阿里云百炼视频模型

这些服务都不是仓库自带的免费接口，需要你准备可用账号、Key、模型名和服务地址。不同上游支持的时长、清晰度和画幅可能不同。

### 6. 合成成片

完成的视频片段可以继续添加原声、音效和 BGM，再合成为成片。合成、转码和部分媒体处理需要本机安装 FFmpeg 与 ffprobe。

## 独立工作台

| 工作台 | 适合做什么 | 需要准备 |
| --- | --- | --- |
| 图片工作台 | 单独生成或整理图片，不必先创建完整短剧流程 | 图片 API |
| 视频工作台 | 快速提交单个视频任务并管理结果 | 视频 API |
| 节点画布 | 自由连接文本、角色、图片、视频、音频和导出节点 | 在画布设置中单独配置模型 |
| 任务中心 | 查看等待中、生成中、成功和失败的任务 | 无额外配置 |
| 3D 导演 | 摆放人物、道具和相机，辅助确定画面与机位 | 支持 WebGL 的浏览器 |

## 对话、图片和语音

- 对话：适配 OpenAI Chat Completions 风格的服务，用于改编、分析、提示词和结构化修复。
- 图片：包含 OpenAI Images、Gemini、火山 Seedream，以及部分异步图片服务的适配逻辑。
- 语音：当前使用 MiMo TTS 兼容格式；部分成片功能还能使用 ElevenLabs 音效与转写。
- 音乐：成片流程可以使用已有音频或相关后台能力，但独立“音乐模型”设置还没有完整开放。

第三方接口经常会调整模型名、参数和返回格式。仓库里存在适配代码，不等于每一家服务、每一个模型都能免配置直接使用。遇到问题时，请先做一个低成本的小请求。

## 项目、备份与跨设备使用

- 项目默认保存在当前浏览器。
- 支持项目和流程快照的导入、导出。
- 没有虾客漫账号登录，也没有自动云同步。
- 更换浏览器或电脑前，请先导出项目备份。
- 超大图片和视频可能受到浏览器存储空间限制。

## 社区版不包含什么

- 不附送模型 Key、共享额度或免费生成次数。
- 不包含登录、注册、充值、支付和站内积分系统。
- 不包含本地大模型、模型权重、语音包或桌面安装包。
- 不承诺所有第三方上游始终兼容。

如果你只想在自己的电脑上使用，通常只需要安装 Node.js、启动项目并填写自己的 API。需要多人共享或公网访问时，请继续阅读 [部署指南](DEPLOYMENT.md) 和 [安全说明](../SECURITY.md)。
