# 功能清单

状态定义：

- **可用**：已有 UI/路由入口，能在依赖满足时完成对应流程。
- **条件可用**：代码已接入，但依赖外部模型、FFmpeg、数据库、对象存储或本地服务。
- **未开放**：存在配置类型或后端基础设施，但当前 UI 没有完整入口。

## 模型与媒体

### 对话

主工作流调用 OpenAI Chat Completions 兼容格式。BFF 在服务端注入系统提示词和结构化修复规则，支持普通与流式返回。

### 图片

当前客户端根据地址和模型识别以下协议：

- Gemini 内容生成格式
- OpenAI Images generations/edits
- 火山方舟 Seedream images
- APIMart 异步图片任务
- Xiakeman/Artlist 兼容异步图片接口

图片代理、跨域下载、参考图压缩和后台图片任务均已有实现，但最终可用性由上游协议兼容性决定。

### 视频

设置界面当前开放：

- 本地 Seedance 服务
- Seedance 兼容云端
- 小云雀 Agent
- 火山方舟 Seedance 官方 API
- 阿里云百炼 HappyHorse

类型中仍保留 `hmapi` 兼容值，但当前主设置界面没有 HM 通道按钮，旧直连提交文件已作为不可达代码删除，因此不把它列为可用通道。

### 语音、音效和音乐

- 语音设置页已开放，当前客户端按 MiMo TTS Chat Completions 音频格式调用，支持预设、声音设计和声音克隆参数。
- ElevenLabs 音效生成和语音转写在成片/媒体链路中按需调用。
- BFF 有 TTS 与 BGM 后台 handler，成片工作台可以使用已有/外部音频。
- “音乐模型”设置标签当前禁用，不能据此宣称独立音乐模型配置已完成。
