# 使用前先了解

虾客漫可以完成一条很长的 AI 视频制作流程，但它不是“安装后无限免费生成”的一体化平台。提前了解下面这些边界，会少走很多弯路。

## 需要自己的模型服务

对话、图片、视频、语音和音效都依赖外部 API。仓库不附送 Key、模型额度、本地模型或上游账号。

第三方服务可能随时调整模型名、价格、参数、地区限制、CORS 和返回格式。程序已经适配一些常见协议，但不能保证所有厂商和模型一直可用。第一次连接请从低成本小任务开始。

## 项目主要保存在浏览器

开源版没有登录和自动云同步。项目、流程和 API 设置主要保存在当前浏览器：

- 清理浏览器数据可能删除项目。
- 换电脑或换浏览器前需要手动导出备份。
- 超大媒体会受到浏览器存储配额和内存限制。
- 这不是多人实时协作编辑工具。

重要项目请养成阶段性导出的习惯。

## 主工作流和画布设置相互独立

右上角“API 设置”与节点画布里的“画布设置”是两套配置。主流程能生成，不代表画布已经选好同一个模型，反过来也一样。

## 音视频处理需要额外工具

成片合成、音频转视频和部分媒体分析需要 FFmpeg 与 ffprobe。视频、图片和渲染同时运行时会明显占用网络、内存、CPU 和磁盘空间。

## 还有一些能力没有完整开放

- 独立“音乐模型”设置还没有完整开放，但可以在成片流程中使用已有音频或相关服务。
- 某些旧项目字段仍然保留，是为了让以前保存的项目能继续打开。
- BFF 中保留了账号、云项目、管理和 Agent 的兼容接口，但开源版前台没有对应登录或管理页面。
- 项目没有附带历史自动化测试套件；已完成构建、启动和浏览器冒烟验证，不代表所有第三方模型组合都经过真实付费测试。

## 不建议把默认开发服务直接暴露到公网

默认配置主要方便本机使用。部分媒体代理、渲染和兼容接口没有完整的用户权限体系。如果需要局域网或公网共享，请先配置 HTTPS、来源限制、速率限制、上游白名单、持久化数据目录和备份，并限制不使用的后台接口。

详细做法见 [部署指南](DEPLOYMENT.md) 和 [安全说明](../SECURITY.md)。

## 适合什么场景

这个版本更适合个人创作者、小团队研究流程、搭建自己的模型工作台，以及在源码基础上二次开发。它不包含计费、支付、共享积分和商业 SLA，不适合未经加固就直接作为公共生成平台运营。
