# 已知限制

## 版本边界

这是 2026-07-02 源码快照的社区整理版，不是当前私有完整版，也不包含之后开发的视频转绘/本地化等新功能。功能判断只针对本目录当前代码。

## 不是完整商业系统

- 社区版没有站内积分、支付、充值、发票、套餐、配额结算或上游账号池。
- Canvas 中保留积分抽象以兼容原始架构，但 `creditsEnabled` 固定关闭；不可达充值弹窗已删除。
- 社区前台不提供账号、管理后台、Agent Key 或项目自动云同步入口。

## 外部依赖决定实际可用性

- 所有 LLM、图片、视频、语音和音乐生成都依赖用户自己的第三方服务。
- 第三方协议、模型名、额度、CORS 和返回格式变化可能导致调用失败。
- 本地 Seedance 和 Seedance 兼容云端不是仓库内置服务。
- 成片合成、音频转视频和部分媒体分析要求 FFmpeg/ffprobe。

## 部分能力没有完整入口

- 音乐模型设置标签当前禁用；BGM handler 存在不等于完整音乐配置体验已完成。
- `hmapi` 仍存在于历史类型和迁移字段中，但当前 API 设置不展示该通道。
- 旧独立 Step 6 配音页已经脱离入口；旧 `dubbing` 状态直接映射到 Step 7 合成。
- Canvas 和主工作流使用两套 provider 设置，用户需要分别配置。

## 存储与扩展

- 默认文件存储只适合单 BFF 实例；多实例并发写普通 JSON 文件没有分布式锁。
- 浏览器本地项目依赖 IndexedDB 配额，超大媒体应使用云 blob/对象存储。
- 跨设备迁移依赖项目或工作流快照导入导出，不是多人实时协同编辑。
- 若自行接入保留的 BFF 账号/云协议，生产环境仍必须持久化服务端加密密钥和数据目录。

## 安全边界

- 浏览器 BYOK 会把 Key 保存在本机浏览器存储，不适合不可信共享电脑。
- `/api/render`、媒体代理和小云雀代理没有统一用户认证，不能原样暴露在公网。
- BFF 仍保留认证/管理路由，但社区前台不调用；公网部署仍应在反向代理层限制这些路由。
- 开发环境允许较宽松的上游地址；生产环境应明确配置白名单。

## 验证边界

- 历史测试目录已从开源快照中移除，当前质量门主要是 TypeScript/Vite 构建、BFF 语法/启动、依赖审计和浏览器冒烟。
- ESLint 仍有原项目继承的技术债：本次全量检查为 273 个 error、93 个 warning，主要是 `any`、未使用变量和 React hooks 规则；构建通过不代表 lint 为零。
- 没有真实第三方 Key 时，只能验证设置、路由和错误处理，不能证明每个外部模型端到端成功。

## 性能边界

- 前端包含画布、Three.js 和大量工作流模块，构建会产生较大的 chunk 警告。
- worker 默认代码上限偏高，部署者应通过 `.env` 从保守并发开始。
- 视频与渲染同时运行时会放大磁盘、网络和内存压力，需要监控任务队列和临时目录。
