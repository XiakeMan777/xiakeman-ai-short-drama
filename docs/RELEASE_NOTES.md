# 版本说明

## 0.8.0 Community

这是面向个人创作者和小团队的开源版本。

### 主要内容

- 提供从剧本、小说改编到角色、场景、故事板、视频和成片合成的完整源码。
- 保留图片、视频、节点画布和任务中心等独立工作台。
- 开放用户自定义对话、图片、视频和语音 API。
- 项目默认保存在浏览器，支持本地导入和导出。
- 前台不要求注册或登录，右上角保留交流群入口。
- 使用正式版虾客漫 Logo，并保留 Google Analytics 页面访问统计。

### 仓库没有包含

- 任何真实 API Key、共享额度、账号数据或内部服务地址。
- `node_modules`、构建结果、桌面安装包和发布压缩包。
- 语音包、语料库、本地模型、模型权重和生成媒体。
- 登录、支付、充值和站内积分服务。

第一次使用请从 [README](../README.md) 开始。模型连接方法见 [API 配置指南](API_CONFIGURATION.md)。
