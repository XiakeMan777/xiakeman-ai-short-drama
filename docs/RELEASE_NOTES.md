# 版本说明

## 0.8.0 Community.2 · 2026-08-26

这一版主要新增火山方舟 Seedance 2.5，并让主流程和独立视频工作台都能根据所选模型自动使用正确的素材上限。

### Seedance 2.5

- 新增火山方舟模型 `doubao-seedance-2-5-260628`。
- 支持最多 30 张参考图、10 个参考视频、10 个参考音频，三类素材合计最多 50 个。
- 支持 4～30 秒视频，以及 480p、720p、1080p 分辨率。
- 普通参考生成与连续镜头续写会分别提交对应的 2.5 任务类型。
- Step4 故事板规划、参考图预算、最终视频提示词和 Step5 提交校验已统一使用模型能力，不再固定写死 9 张图。
- 独立视频工作台现在可以直接选择火山方舟和 Seedance 2.5。

### 兼容与修正

- 只有选择 Seedance 2.5 时才开放新上限；切回 Seedance 2.0 会自动恢复 9 图、3 视频、3 音频和最长 15 秒限制。
- 修正设置界面中一处仍显示旧“9 图 / 3 视频 / 3 音频”的说明。
- 新增新旧模型提示词模板回归测试，防止旧模型限制被意外放开。
- 更新功能说明和 API 配置指南，方便用户判断不同模型的能力范围。
- README 增加首页预览图和 [xiakeman.com](https://xiakeman.com) 在线预览入口。

本次验证包括生产构建、UTF-8 检查、本地浏览器启动和新旧模型界面切换。测试过程没有提交真实付费视频任务。
