# API 配置指南

社区版不附带模型 Key。你可以使用自己已有的对话、图片、视频和语音服务，费用由对应服务商收取。

## 开始之前

准备好以下信息：

- 服务地址，也叫 Base URL 或 API URL
- API Key、Access Key 或服务商提供的许可证
- 模型名
- 该服务支持的画幅、时长、清晰度等参数

不要把 Key 写进源码、截图、Issue 或群聊。建议使用有额度上限的测试 Key，先完成一次小请求。

## 主工作流怎么配置

打开虾客漫，点击页面右上角“API 设置”。主工作流里的配置会保存在当前浏览器中。

### 对话模型

对话模型负责小说改编、内容分析、分集设计、故事板规划和提示词整理。

填写：

1. API 地址，例如 `https://provider.example/v1`
2. API Key
3. 模型名

当前调用方式接近 OpenAI Chat Completions。程序会在基础地址后使用 `/chat/completions`；如果你的网关已经带有代理路径，请确认最终地址没有重复的 `/v1` 或 `/chat/completions`。

### 图片模型

图片模型用于角色图、场景图、道具图、参考图和故事板出图。

填写服务地址、Key 和模型名后，先用单张、低分辨率图片测试。程序包含 OpenAI Images、Gemini、火山 Seedream 和部分异步图片服务的适配，但自建网关或新模型仍可能有参数差异。

如果上传本地图片，不需要图片 API。

### 视频模型

在视频设置中选择与你实际服务对应的通道：

| 通道 | 通常需要填写 |
| --- | --- |
| 本地 Seedance | 本地兼容服务地址 |
| Seedance 兼容云端 | 服务地址、许可证或 Key、模型 |
| 小云雀 Agent | Agent 地址和 Access Key |
| 火山方舟 | Base URL、API Key、Seedance 模型 |
| 阿里云百炼 | API Key、区域和模型 |

不同服务支持的时长、画幅、分辨率和参考图数量不同。界面会尽量修正不支持的组合，但最终仍以上游实际规则为准。

### 语音、音效和转写

语音设置使用当前 MiMo TTS 兼容格式，可配置预设声音、声音设计和声音克隆。声音克隆需要你有权使用的参考音频。

部分音效生成和语音转写功能使用 ElevenLabs 接口，需要单独的 Key。请确认音频素材和克隆声音已获得授权。

## 为什么节点画布还要再配置一次

主工作流和节点画布是两套独立设置：

- 右上角“API 设置”服务于短剧主流程、图片工作台和视频工作台。
- 节点画布内部的“画布设置”服务于画布节点。

一边保存的模型不会自动覆盖另一边。这样可以让画布使用不同服务，但第一次使用时需要各配置一次。

## 配置保存在哪里

Key 和模型配置默认保存在当前浏览器，不会同步到虾客漫账号。请注意：

- 同一浏览器配置文件的其他使用者可能读取这些信息。
- 清理网站数据后，配置可能丢失。
- 浏览器直连上游时，上游必须允许 CORS。
- Key 会发送到你填写的服务地址，保存前请仔细检查域名拼写。

## 常见报错

### 401 或“API Key 无效”

检查 Key 是否完整、是否已启用、是否有余额，以及服务商是否要求特殊请求头。

### 404 或“接口不存在”

检查 Base URL 是否多写或少写了 `/v1`，也要检查模型名是否属于这个接口。

### 浏览器提示 CORS

这是上游没有允许浏览器跨域访问。可以改用支持 CORS 的服务、让服务商开放你的来源，或通过自己部署的 BFF/反向代理转发。不要使用陌生的公共代理传递私人 Key。

### 请求一直等待或视频轮询失败

先到服务商后台确认任务是否真的提交成功，再检查网络、额度、模型参数和任务查询接口。视频生成时间较长，反向代理的超时也要足够大。

### 保存后刷新变空

确认浏览器没有开启自动清理网站数据，也没有使用禁止持久化存储的隐私模式。主工作流和画布设置互不通用，请确认查看的是同一套设置。

## 自己部署时的地址白名单

如果把 BFF 放到局域网或公网，建议只允许它访问你确实使用的上游域名：

```dotenv
LLM_BASE_URL_ALLOWLIST=api.openai.com,provider.example
IMAGE_BASE_URL_ALLOWLIST=image-provider.example
TTS_BASE_URL_ALLOWLIST=tts-provider.example
MUSIC_BASE_URL_ALLOWLIST=music-provider.example
XYQ_AGENT_BASE_ALLOWLIST=xyq.jianying.com
```

只填写主机名，不要填写路径和 Key。生产环境不要把 localhost、云元数据地址或不受控的内网地址开放给普通用户。更多内容见 [部署指南](DEPLOYMENT.md)。
